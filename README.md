# 📋 Student ID Card Generator

A professional HTML-based application that allows you to enter student details and generate a printable ID card instantly.

## ✨ Features

- **📸 Photo Upload** - Upload and preview student photos
- **📝 Comprehensive Form** - Collect all necessary student information
- **🎨 Professional Design** - Modern gradient-based ID card template
- **🖨️ Print Ready** - Generate printable ID cards (save as PDF)
- **📱 Responsive Design** - Works on desktop, tablet, and mobile devices
- **⚡ Real-time Generation** - ID card updates instantly as you fill the form
- **🔄 Form Reset** - Clear form to start over
- **🎯 User Friendly** - Simple and intuitive interface

## 📋 Student Information Collected

### Required Fields (*)
- **Full Name** - Student's complete name
- **Roll Number** - Unique roll number (e.g., CS2024001)
- **Student ID** - Student's ID number (e.g., 12345678)
- **Department** - Department/Course name
- **Semester** - Academic semester (1-8)
- **Issue Date** - Card issue date (auto-filled with today's date)
- **Expiry Date** - Card expiration date

### Optional Fields
- **Student Photo** - Profile photograph
- **Email** - Email address
- **Phone** - Contact number
- **Date of Birth** - Student's DOB
- **Blood Group** - Blood type (A+, A-, B+, B-, AB+, AB-, O+, O-)
- **Address** - Residential address

## 🚀 How to Use

### 1. **Open the Application**
   - Download `student-id.html` and open it in any web browser
   - Or use it directly from: [GitHub Repository](https://github.com/hari-shreyas-varma/student-idcard-maker)

### 2. **Fill in Student Information**
   - Upload a student photo (click "Choose File")
   - Enter all required fields (marked with *)
   - Fill optional fields as needed
   - Issue Date is auto-filled with today's date

### 3. **Generate ID Card**
   - Click the **"Generate ID Card"** button
   - The professional ID card will appear on the right side
   - A success message will confirm generation

### 4. **Print or Save**
   - Click **"🖨️ Print ID Card"** button
   - Choose "Save as PDF" from the print dialog
   - Or directly print to physical paper

### 5. **Start Over**
   - Click **"Clear Form"** to reset all fields

## 🔧 Customization

You can customize the ID card by editing the CSS in the HTML file:

- **Colors:** Change gradient colors in `.id-card` class
- **Card Size:** Modify `height` and `width` in `.id-card` class
- **Font:** Change `font-family` in `body` style
- **Title:** Modify "STUDENT ID CARD" text in the HTML
- **Layout:** Adjust grid layout in `.container` class
